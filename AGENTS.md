# How This Site Is Built

- **Static site only:** Use HTML, CSS, and plain JavaScript. No frameworks, no build step, no npm, and no server. Use JavaScript state and localStorage to save course information.

- **No backend services:** If a feature requires a server, database, login, payment system, or external API, stop and tell me. Add it to the Later section of PRD.md instead of implementing it.

- **Follow the design:** All styles must be in `css/styles.css` and follow `DESIGN.md`. If a new color, font, or size is needed, ask me before adding it.

- **Follow the requirements:** Build only the GPA & Grade Calculator features described in `PRD.md`. Ask before adding new pages, sections, or features.

- **File organization:** Use lowercase file and folder names with hyphens and no spaces. Keep the JavaScript readable and easy for a beginner to understand.
